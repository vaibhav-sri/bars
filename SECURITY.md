# Security Policy

## Supported Versions

Currently, only the latest version of Bars on the `master` branch is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within Bars, please do not disclose it publicly. Instead, please open a private security advisory on GitHub or email the maintainer directly. 

We take all security vulnerabilities seriously and will work to resolve the issue as quickly as possible. You will receive a response within 48 hours acknowledging receipt of the vulnerability.
